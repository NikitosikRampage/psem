# Profi.ru — автоотклики (MVP)

Десктоп-приложение на Python, которое откликается на заказы Profi.ru из **вашего уже открытого Chrome**.
Логин и пароль не нужны: бот подключается к запущенному браузеру через Chrome DevTools Protocol
(Playwright `connect_over_cdp`), открывает в нём свою вкладку и работает с вашими куками.

## Возможности

| Вкладка | Что настраивается |
|---|---|
| **Фильтры** | категории, ключевые слова и стоп-слова, бюджет от/до (и брать ли заказы без бюджета), гео, дистанционные заказы, тип клиента (частное лицо / компания) |
| **Шаблоны** | несколько шаблонов с переменными `{name}` `{my_name}` `{price}` `{deadline}` `{title}` `{category}` `{budget}`, ротация «по очереди» или «случайно», предпросмотр |
| **Цены** | фиксированная, «от», диапазон или формула от бюджета (`budget * 0.9` = бюджет −10%), округление, мин/макс; тип отклика: платный / за комиссию, приоритет между ними, % комиссии |
| **Лимиты** | откликов в день и в час, платных в день, бюджет на платные в день; при достижении — автостоп или пауза до освобождения лимита; задержка перед откликом и интервал между откликами (случайные в диапазоне, сек/мин); рабочие часы и дни недели |
| **Логи** | статистика за сегодня, таблица откликов, журнал событий, экспорт в CSV / Excel, уведомления в Telegram |

Кнопки **Старт / Пауза / Стоп** управляют ботом; **Сохранить** применяет настройки даже на ходу.
По умолчанию включён **тестовый режим (dry run)**: бот находит заказы и заполняет форму, но не нажимает «Отправить».

## Установка

Нужен Python 3.10+ с Tkinter (в Windows/macOS идёт в комплекте; в Ubuntu: `sudo apt install python3-tk`).

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows;  source .venv/bin/activate — Linux/macOS
pip install -r requirements.txt
```

`playwright install` не обязателен — используется ваш собственный Chrome.

## Запуск

1. **Закройте все окна Chrome** и запустите его с портом отладки (отдельный профиль обязателен
   в Chrome 136+, иначе порт не откроется):

   ```bash
   # Windows
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="%LOCALAPPDATA%\ProfiBotChrome"
   # macOS
   /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222 --user-data-dir="$HOME/.profibot-chrome"
   # Linux
   google-chrome --remote-debugging-port=9222 --user-data-dir="$HOME/.profibot-chrome"
   ```

2. В этом окне Chrome **войдите в Profi.ru** как обычно (один раз — профиль запомнит вход).
   Проверить порт: откройте http://127.0.0.1:9222/json/version — должен показаться JSON.
3. Запустите приложение:

   ```bash
   python -m profi_bot                # окно с настройками
   python -m profi_bot --headless     # без окна, по config/settings.yaml (Ctrl+C — стоп)
   ```

При первом запуске `config/settings.yaml` создаётся из `config/settings.example.yaml`
(файл в `.gitignore`, т.к. может содержать токен Telegram).

## ⚠️ Настройка селекторов (обязательно перед боевым режимом)

Разметка кабинета Profi.ru закрыта авторизацией и периодически меняется, поэтому
URL ленты и CSS-селекторы вынесены в [`config/selectors.yaml`](config/selectors.yaml) — значения там стартовые.

1. Откройте ленту заказов в своём Chrome → F12 → Elements, найдите карточку заказа.
2. Укажите в `orders_urls` адрес(а) ленты (можно несколько, например по категориям),
   в `list.*` — селекторы карточки и её полей, в `order_page.*` — кнопки «Откликнуться»,
   переключателей типа отклика, полей цены/комиссии/текста и кнопки «Отправить».
3. Запустите бота в **тестовом режиме** и смотрите вкладку «Логи»: «В ленте N заказов» и
   «Форма заполнена, не отправлено» означают, что селекторы подходят. Во вкладке Chrome, которую
   открывает бот, видно, как заполняется форма.
4. Снимите галочку «Тестовый режим» — заказы, обработанные в тесте, станут снова доступны.

## Как это работает

```
лента заказов → новые (не виденные ранее) → фильтры → рабочие часы и лимиты
 → случайная задержка → страница заказа → выбор типа отклика по приоритету
   (платный отключается, если исчерпан лимит платных или бюджет)
 → цена → шаблон (ротация) → заполнение формы → отправка → SQLite / лог / Telegram
 → случайный интервал → … → повторная проверка ленты через «Опрос, сек»
```

Каждый заказ обрабатывается один раз (SQLite, `data/profi_bot.db`). Лог работы — `data/profi_bot.log`.
Стоп закрывает только вкладку бота; ваш Chrome остаётся открытым.

## Структура

```
profi_bot/
  browser.py        подключение по CDP, парсинг ленты, заполнение формы отклика
  engine.py         рабочий поток: цикл, пауза/стоп, лимиты, задержки
  filters.py        фильтры заказов
  pricing.py        режимы цены, безопасный калькулятор формул
  templates.py      переменные и ротация шаблонов
  response_type.py  выбор платный / за комиссию
  scheduler.py      рабочие часы, случайные задержки
  limits.py         лимиты день/час/платные/бюджет
  storage.py        SQLite, статистика, экспорт CSV/XLSX
  notifier.py       Telegram
  ui/app.py         Tkinter-интерфейс
config/
  settings.example.yaml, selectors.yaml
tests/              юнит-тесты + сквозной тест с настоящим Chrome и фейковым сайтом
```

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

`tests/test_integration.py` поднимает локальную копию ленты и формы отклика, запускает Chromium с
`--remote-debugging-port` и прогоняет движок целиком (фильтры, приоритет типов, формула цены,
ротация шаблонов, dry run, лимиты, автостоп). Нужен Chromium для Playwright
(`playwright install chromium`), иначе тест пропускается.

## Важно

Автоматизация действий на сайте может противоречить правилам Profi.ru. Используйте разумные
лимиты и задержки, начинайте с тестового режима; ответственность за использование — на вас.
